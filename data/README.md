# data 目录 —— 本地数据存放

本目录存放筛选工具使用的本地数据文件。除 `themes.json`（自定义题材配置，已入库）外，
其余均为程序运行时生成的缓存，**不纳入 Git 版本控制**。

## 目录结构

```
data/
├── daily/             # 日线 K 线缓存 {code}.csv（筛选用，约 120-260 根）
├── weekly/            # 周线 K 线缓存
├── monthly/           # 月线 K 线缓存
├── full/daily/        # 全量历史 K 线（看图用，上市至今；{code}.fq 标记复权方式）
├── industry.json      # 个股行业归属缓存（东财 f100，7 天有效）
├── concepts.json      # 概念题材索引缓存（7 天有效，含 em / tdx 两个源）
├── themes.json        # 【入库】自定义题材配置（精确名单 + 别名映射）
├── universe.csv       # 全市场股票池缓存
└── sync_meta.json     # 上次数据同步时间
```

## 各文件说明

| 文件 | 生成方式 | 有效期 | 说明 |
|---|---|---|---|
| `daily/ weekly/ monthly/` | 「服务器」连接后增量同步，或首次筛选时按需拉取 | 永久（追加式） | 筛选引擎的输入，只读缓存不重复下载 |
| `full/daily/` | 打开 K 线图时按需拉取（每段 800 根分段拉全） | 6 小时 | 前复权；出现负价（累计分红 > 股价）时整只切后复权并写 `{code}.fq` |
| `industry.json` | 筛选完成后只对**命中股票**查一次 | 7 天 | 行业分类变动慢，报告「行业分布」用 |
| `concepts.json` | 首次生成报告时构建（东财 531 + 通达信 269 个板块） | 7 天 | 报告「概念题材分布」用；结构 `{"_ts", "em", "tdx"}` |
| `themes.json` | **手工维护** | 即时生效 | 见下节 |
| `universe.csv` | 首次运行自动拉取全市场 A 股列表 | 长期 | 股票池 |
| `sync_meta.json` | 每次同步结束写入 | — | 界面「上次同步」显示用 |

## 自定义题材 `themes.json`

用于补公开数据源里确实没有的市场新词（如「太空算力」「AI短剧」「物理AI」）。

```json
{
  "_alias": {
    "AI短剧": ["短剧游戏", "短剧互动游戏"],
    "物理AI": ["人形机器人"]
  },
  "太空算力": ["600118", "600879", "603019"]
}
```

- **精确名单**：键=题材名，值=6 位股票代码数组
- **别名映射** `_alias`：键=市场新词，值=[已有板块名] → 该板块的成分股都会被打上这个新词
  （成分股跟随来源板块，不凭空编造）
- 以 `_` 开头的键是配置/注释，不会被当成题材
- **改完保存即生效**（按文件修改时间热加载），重新生成报告即可，不用重启服务

> 为什么需要手工补：`AI短剧`「物理AI」「太空算力」等在**东财 531 个、同花顺 361 个、
> 通达信 269 个公开概念板块里都不存在**（最接近的是“短剧游戏”“人形机器人”“算力概念”），
> 它们只存在于 iFinD / Choice 等机构终端与研报中，免费接口拿不到成分股名单。

## 说明

- 删除 `daily/weekly/monthly/` 后，可通过「服务器」连接重新全量同步；
  也可用 `python app/repair_cache.py --dry-run` 先体检是否存在日期断层。
- 删除 `industry.json` / `concepts.json` 后，下次生成报告会自动重建（概念约 15 秒）。
