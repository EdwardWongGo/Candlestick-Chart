# data 目录 —— 本地数据存放

本目录存放筛选工具使用的本地数据文件（均不入库，由程序运行时生成/同步）。

## 目录结构

```
data/
├── daily/         # 日线 K 线缓存（{code}.csv）
├── weekly/        # 周线 K 线缓存
├── monthly/       # 月线 K 线缓存
├── universe.csv   # 全市场股票池缓存
└── sync_meta.json # 上次数据同步时间
```

## 数据来源

- **K 线缓存**（daily/weekly/monthly）：由「数据来源 → 服务器」连接后同步生成，
  或首次筛选时自动从通达信拉取并落盘。
- **universe.csv**：首次运行时自动拉取全市场 A 股列表。
- **sync_meta.json**：记录上次同步时间，供界面展示。

## 说明

- 数据文件为运行时产物，不纳入 Git 版本控制。
- 删除本目录数据后，可通过「服务器」连接重新全量同步。
