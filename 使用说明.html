📊 A股蜡烛图形态筛选工具 · 使用说明

照着下面的步骤做，任何人都能把这个工具跑起来。不需要懂编程。

一、一键安装（推荐，只需运行一次）

项目自带 install.bat 一键安装脚本，自动完成：Python 环境检查、虚拟环境创建、依赖包安装、数据目录生成、安装自检验证。运行一次即可完成全部设置。

  1. 前置条件：一台能上网的 Windows 电脑（Win10 / Win11）+ 已安装 Python 3.10 或更高版本。
    检查方法：按 Win+R 输入 cmd 回车，输入 python --version，
    若显示 Python 3.x.x 即可；若提示「不是内部或外部命令」，请先到 python.org/downloads 下载安装（安装时勾选 Add Python to PATH）。
  2. 进入项目目录，双击 install.bat，按提示等待脚本执行（首次约需 1~3 分钟）。
  3. 看到「安装完成！」即成功。接着双击 启动筛选工具.bat 即可运行工具。
💡 脚本会自动完成以下事情：
· 检测 Python 版本（低于 3.10 会提示先升级）
· 创建虚拟环境 .venv（依赖与系统隔离，互不干扰）
· 安装全部依赖包（默认走清华 PyPI 国内镜像加速，失败自动回退官方源）
· 生成 data\daily weekly monthly 数据目录
· 运行形态引擎自检（17 项用例），自检通过即安装正常
💡 手动安装（可选）：打开命令行进入项目目录，执行
pip install -r requirements.txt
出现 Requirement already satisfied 属正常，说明之前装过。

二、启动程序（3 步）

  1. 进入项目目录，双击 启动筛选工具.bat。
    脚本会自动优先使用一键安装创建的虚拟环境（.venv），其次回退到系统 Python；
    也可手动运行 .venv\Scripts\python run.py 或 python run.py。
  2. 稍等 1~3 秒，浏览器会自动打开工具页面（网址 http://127.0.0.1:8000）。
    如果浏览器没有自动打开，请手动在浏览器地址栏输入 http://127.0.0.1:8000 回车。
  3. 看到「数据来源」「开始筛选」等界面即启动成功。
💡 程序在后台运行（pythonw.exe），启动时的黑色窗口可以关闭，关掉不影响使用。
运行日志见项目目录下的 服务日志.log（启动过程在 启动日志.log）。
💡 要停止程序，双击项目目录下的 停止筛选工具.bat。
⚠️ 若双击 .bat 一闪而过 / 报错，请看下方「常见问题」第 1、2 条。

三、同步数据（让工具有行情数据可用）

工具默认会同步 日线 / 周线 / 月线 三个时间维度的全市场数据到本机。操作如下：

  1. 在页面左侧「数据来源」里选择 🌐 服务器。
  2. 选择「数据服务器」（下拉框，说明已标注数据出处与适用场景）：
    选项数据出处什么时候用
    通达信公开行情 · 生产主用通达信官方行情网络（公网）默认首选，绝大多数网络可用
    腾讯财经 K 线 · 生产兜底腾讯财经公开接口通达信连不上 / 被拒绝时自动兜底
    新浪财经 K 线 · 备用节点新浪财经公开接口备用，日线/周线可用
    自定义服务器 · 内网/专线你自己填的地址（主机:端口）公司内网或专线行情源
  3. 「同步级别」默认勾选 日线 / 周线 / 月线（可按需取消勾选）。
  4. 点击 🔌 连接，等待进度条走完（全市场约需数分钟，属正常）。
  5. 看到「✅ 同步完成：N 项写入本地」即可开始筛选。
💡 同步就是把服务器上的 K 线下载到本机 data/ 文件夹，之后筛选不用联网、速度快。同步失败或提示「未获取到数据」时，换一个「数据服务器」再试即可。

四、开始筛选

  1. 在「时间级别」勾选要筛选的级别（日线 / 周线 / 月线，可多选）。
  2. 在「形态」中选择要识别的蜡烛图形态（默认全选）。
  3. 按需设置附加条件：涨跌幅、放量倍数、价格区间、只看年线上方、是否包含 ST 等。
  4. 点击 开始筛选，等待进度条完成，结果表会列出命中的股票。
  5. 点结果行可查看 K 线图（形态位置高亮）；点「导出 CSV」可导出到 Excel。

五、常见问题排查

1. 双击启动文件一闪而过 / 打不开？ 说明依赖没装好。按「一、环境准备」第 3 步执行 pip install -r requirements.txt 后重试。 还不行的话，打开命令行运行 python run.py，把红色报错信息截图发给维护者。
2. 提示「端口被占用」或页面打不开？ 说明 8000 端口被其他程序占用。改用其它端口启动：命令行运行 python run.py --port 8001，然后浏览器访问 http://127.0.0.1:8001。
3. 同步后只有「日线」文件夹，没有周线/月线？ 同步级别没勾全。回到「三、同步数据」第 3 步，勾上 周线 和 月线，再点一次「连接」。
4. 提示「同步完成，但 N 项未获取到数据（数据源无返回）」？ 当前选的数据服务器暂时拿不到数据。在「数据服务器」下拉换一个选项（例如换成「腾讯财经 K 线」）再同步一次。
5. 涨停板 / 龙虎榜 / 题材热点是空的？ 这些数据在交易日盘后才发布。盘中或周末查询当天数据为空属正常；程序会自动取最近一个已收盘交易日的数据。稍后再试即可。
6. 数据不是最新的？ 数据只更新到最近一次同步的时刻。重新点「🔌 连接」即可增量更新（只下载新增部分，很快）。
7. 某些股票没有数据？ 停牌股没有新 K 线，会被跳过（正常）；新股历史太短、K 线根数不够，也算不了形态（正常）。
8. 怎么停止程序？ 双击项目目录下的 停止筛选工具.bat 即可（脚本会结束占用 8000 端口的进程）。
注意：关闭启动时那个黑色窗口不会停止程序——新版已改为后台独立进程， 这样关窗口不会把正在跑的同步/筛选任务一起杀掉。
9. 一键安装脚本（install.bat）提示「未检测到 Python」？ 说明电脑未安装 Python 或未加入 PATH。先到 python.org/downloads 安装 Python 3.10+ （务必勾选 Add Python to PATH），再重新双击 install.bat。
10. 安装脚本下载依赖很慢或报错？ 脚本默认使用清华 PyPI 国内镜像加速，失败会自动回退官方源。若两者都失败，通常是网络问题： 检查网络后重新运行 install.bat 即可，已下载好的包不会重复下载。
11. 重复运行安装脚本安全吗？ 安全。脚本设计为可重复执行（幂等）：虚拟环境已存在会跳过创建、依赖已安装会显示 already satisfied、数据目录已存在会跳过，不会破坏现有环境。

六、启动失败？用 WorkBuddy 自助排查

双击启动没反应、浏览器打不开、页面报错——不用等人。把项目文件夹交给 WorkBuddy（桌面 AI 助手）， 让它读日志、查端口、查依赖，通常一两分钟就能定位原因并直接修好。

第 1 步：把项目文件夹交给它

  1. 打开 WorkBuddy，新建一个会话。
  2. 把项目文件夹（包含 run.py、启动筛选工具.bat 的那一层）拖进对话框， 或在它的工作目录里指向该文件夹。
  3. 测试是否接好：问一句「当前目录有哪些文件」，能列出来就说明可以正常读写。
💡 它是本机 AI 助手，可以直接读文件、执行命令。所以这不是“猜原因”， 而是真的去读你的日志、查你的端口、看你的进程。

第 2 步：直接粘贴这段提示词

项目目录：D://量化开发//蜡烛图（换成你电脑上的实际路径） 现象：双击「启动筛选工具.bat」后，浏览器打开 http://127.0.0.1:8000 显示「无法访问此网站」。 请按这个顺序排查，每一步把结果告诉我，最后直接修好： 1. 读 启动日志.log 和 服务日志.log 的最后 50 行，找出报错信息 2. 查 8000 端口有没有被别的程序占用 3. 检查 .venv 是否存在、依赖是否齐（flask / pandas / mootdx 能否 import） 4. 查有没有卡死的 pythonw.exe 残留进程 5. 定位原因后直接改，改完告诉我怎么验证、要不要重启服务 注意：只做诊断和修复，不要批量拉取行情数据。

第 3 步：按症状选一行（可以接着追加上面的提示词）

你看到的现象让它查什么通常是
双击 .bat，窗口一闪就消失读 启动日志.log依赖没装好、Python 路径不对
浏览器「无法访问此网站」查 8000 端口 / pythonw.exe 进程服务没起来，或端口被别的程序占了
页面能打开，但筛选结果为空看 data/daily 里有没有 CSV还没同步数据
同步进度卡住 / 一直失败读 服务日志.log 的报错数据源被限流，换个服务器再试
页面样式错乱、没有新功能确认服务是否跑的是最新代码旧进程没重启，或浏览器缓存了旧页面
报告里行业/题材是空的看 data/industry.json、concepts.json本次筛选结果没带画像字段，重新筛选一次

第 4 步：它给出结论后，你只需要两件事

  1. 重启服务：双击 停止筛选工具.bat，再双击 启动筛选工具.bat。
    （后端代码改动必须重启才生效，只刷新页面没用。）
  2. 刷新页面：浏览器按 Ctrl + F5 强制刷新，清掉旧的前端缓存。
⚠️ 三件不要让它做的事：
· 不要批量重拉全市场数据——一次几万请求会触发数据源风控，连通达信 K 线接口都可能被限好几天。诊断只打单只样本。
· 不要删 data 目录——那是几个小时的同步成果，删了要重新同步。
· 不要让它后台闷头跑长任务——同步前先估算耗时，确认能中断再开始。
💡 如果 WorkBuddy 也修不好，把这三样发给维护者，定位会快很多：
① 启动日志.log 与 服务日志.log
② 命令行执行 python run.py 后的完整红色报错
③ Windows 版本 + python --version 的输出
