# A股看盘工具改造方案

> 在不影响现有功能的前提下，重构六大模块。本文档明确每个模块的**数据来源、计算规则、边界条件**与**交互设计**。
> 版本：2026-08-16 · 基于实测数据源验证。

---

## 〇、数据源核实结论（方案的事实基础）

| 数据源 | 端点 | 状态 | 关键约束 |
|---|---|---|---|
| 东财涨停池 | `push2ex/getTopicZTPool` `dpt=wz.ztzt` | ✅ 可用 | 只保留**约 10 个交易日**历史，更早日期返回空 |
| 东财跌停池 | `dpt=wz.dtzt` | ⚠️ 近期返回空 | 牛市期无跌停（龙虎榜佐证无跌幅记录）；需兜底 |
| 东财炸板池 | `dpt=wz.zbzt` | ⚠️ 近期返回空 | 炸板未回封池；需兜底 |
| 同花顺涨停原因 | `zx.10jqka.com.cn/event/api/getharden` | ✅ 可用 | 提供 reason 题材归因 tags |
| 东财龙虎榜 | `datacenter RPT_DAILYBILLBOARD_DETAILSNEW/BUY/SELL` | ✅ 可用 | 支持日期范围查询（近 1 年可查） |
| 东财全球资讯 | `np-weblist/getFastNewsList` | ✅ 可用 | 7×24 快讯，带关联股票 |
| 通达信日线 | mootdx `frequency=4` | ✅ 可用 | 每只 260 根 ≈ 1 年历史，用于涨停次数/连板推导 |

**核心设计原则**：凡是「当日截面」用池接口（精确、含 ST/板块涨跌幅），凡是「历史统计」（一年涨停次数、跌停连板、未封板）用**本地日线 K 线推导**（因为池接口历史仅 10 天）。

## 一、连板天梯

### 需求
- 按连板高度（2板/3板/…/N板）分组，层级展示
- 每组仅保留 4 字段：**代码、名称、连板数、所属题材**
- 新增「跌停连板」子模块
- 支持查看前 5 个交易日

### 数据来源
- **涨停连板**：东财涨停池 `lbc` 字段（连板数）
- **所属题材**：同花顺 getharden `reason` 字段
- **跌停连板**：涨停池无跌停数据 → **本地日线推导**（见下）

### 计算规则
- 涨停连板：`lbc >= 2` 分组；`lbc == 1` 归「首板」
- 跌停连板：对每只股票取日线，判断**连续跌停天数**：
  ```
  跌停判定：close <= 昨收 × (1 - 涨跌幅限制) - 0.001
  涨跌幅限制：主板 10% / 科创创业 20% / 北交所 30% / ST 5%
  连板数 = 从最近一根往前连续满足跌停判定的天数
  ```
- 层级结构：高度降序（N板 → 2板 → 首板）

### 边界条件
- **ST 股涨跌幅 5%**：识别名称含 `ST/*ST`，用 5% 判定
- **上市首日无涨跌幅限制**：上市 5 日内次新股不纳入连板统计
- **停牌股**：无当日数据，跳过
- **历史窗口**：涨停连板仅前 5 交易日（池接口限制）；跌停连板可从本地日线算任意窗口

### 交互
- 塔式层级卡片，顶部显示最高连板高度
- 「涨停连板 / 跌停连板」子 Tab 切换
- 日期选择器（前 5 个交易日）

## 二、龙虎榜

### 需求
- 点击上榜股票 → 详情页：当日席位明细（买卖席位名称、成交额、净买入金额）
- 该股票**近 1 年上榜明细**列表，支持日期升/降序切换
- 支持前 5 个交易日数据

### 数据来源
- 全市场榜单：`RPT_DAILYBILLBOARD_DETAILSNEW`（按日期过滤）
- 席位明细：`RPT_BILLBOARD_DAILYDETAILSBUY` / `RPT_BILLBOARD_DAILYDETAILSSELL`
- 近 1 年明细：`RPT_DAILYBILLBOARD_DETAILSNEW` 按 `(TRADE_DATE>='start')(SECURITY_CODE="code")` 过滤

### 计算规则
- 净买入金额 = 买入额 - 卖出额（字段 `BILLBOARD_NET_AMT`）
- 机构专用席位：`OPERATEDEPT_CODE == "0"` 聚合统计
- 席位成交额：`BUY`/`SELL` 字段（元 → 万元展示）

### 边界条件
- **非交易日**：返回空，显示「无数据（非交易日或盘后未更新）」
- **北交所/ST**：同样上榜规则，无特殊处理
- **近 1 年上限**：单只股票上榜次数通常 < 30 次，datacenter 单次查询足够
- **东财限流**：席位明细逐只查询需节流（每次 ≥0.8s），详情页按需触发

### 交互
- 详情页（弹窗）：顶部机构动向卡片 + 买卖席位 TOP5 双表
- 近 1 年明细列表 + 升/降序切换按钮
- 日期选择器（前 5 个交易日）

## 三、题材热点

### 需求
- 从涨停板股票抓取题材
- **入选门槛：单题材当日 ≥ 2 只涨停股**
- 显示题材对应涨停股数量
- 支持前 5 个交易日

### 数据来源
- 涨停股列表：东财涨停池（前 5 交易日）
- 题材标签：同花顺 getharden `reason` 字段

### 计算规则
- 题材提取：`reason` 按 `+` 切分为多个题材 tag
- 热度统计：词频计数，`count >= 2` 才入选
- 排序：涨停股数量降序

### 边界条件
- **reason 为空**：该涨停股不计入题材统计
- **复合题材**：一只股票的 reason 含多个 tag（如"CPO+算力租赁"），分别计入各题材
- **历史窗口**：池接口仅 10 天，题材热点最多回看 5 交易日（满足需求）
- **题材命名**：同花顺人工运营，同题材可能写法不一，不做归一化（保持原始）

### 交互
- 题材热度榜（排名 + 题材名 + 涨停数），低于 2 只的不显示
- 展开题材 → 该题材涨停股列表（点股票看 K 线）
- 日期选择器（前 5 个交易日）

## 四、周末热点新闻

### 需求
- 改造为「周末热点新闻」模块
- 仅筛选**周五盘后 ~ 周一盘前**时段内的重点新闻，不做全量抓取
- 正确处理周四/周五为法定休假日时「周末」定义变化

### 数据来源
- 东财全球资讯 `np-weblist/getFastNewsList`（7×24 快讯，带时间戳 `showTime`）

### 计算规则
- 周末窗口 = [上周五收盘 15:00, 本周一开盘 09:30)
- 重点新闻筛选：优先带关联股票（`stockList` 非空）、标题含板块/公司/政策关键词

### 边界条件（节假日处理）
- **周五是休市日（法定假日）**：周末窗口起点前移 → [周四收盘, 周一开盘)
- **周一是休市日**：窗口终点后移 → [周五收盘, 周二开盘)
- **周四、周五都是假日**：窗口起点前移到周三收盘
- 判定休市日的规则：**当日涨停池返回空 且 为非周末** → 视为休市日；或维护本地交易日历表
- **长假（如国庆/春节）**：窗口可能跨 7+ 天，新闻较多，需按「重点」筛选（关联股票 + 关键词）

### 交互
- 时间线展示：时间 + 标题 + 摘要 + 关联股票标签
- 顶部标注实际周末窗口（如「8/14 周五收盘 ~ 8/17 周一开盘」）

## 五、涨停板 / 跌停板（含「未封板」子模块）

### 需求
- 删除「烂板」独立模块
- 涨停板、跌停板内各新增「未封板」子模块
- 涨停板股票显示**最近一年/半年/一月涨停次数**
- 支持前 5 个交易日
- 评估一年涨停数据存储容量

### 数据来源
- 涨停/跌停截面：东财涨停池 / 跌停池（前 5 交易日）
- **未封板**：池接口无此数据 → **本地日线推导**：
  ```
  未封板(涨停)：当日 high >= 涨停价 且 close < 涨停价
  未封板(跌停)：当日 low  <= 跌停价 且 close > 跌停价
  ```
- **涨停次数**：本地日线 K 线推导（见计算规则）

### 计算规则
- 涨停判定：`round(close,2) >= round(昨收 × (1+limit),2) - 0.01`
- 涨停次数统计口径：
  - 一年 = 最近 245 个交易日（260 根日线覆盖）
  - 半年 = 最近 122 个交易日
  - 一月 = 最近 21 个交易日
- 涨跌幅限制：主板 10% / 科创创业 20% / 北交所 30% / ST 5%

### 存储容量评估（一年涨停数据）

| 方案 | 存储量 | 说明 |
|---|---|---|
| 涨停快照存储（每日涨停股清单） | **~2 MB/年** | 每日 100 只 × 80 字节 × 245 日 |
| 日线 K 线（已缓存） | 60 MB/全市场 | 260 根/只 ≈ 12 KB/只，已覆盖 1 年，涨停次数可直接推导 |
| 涨停次数预计算表 | ~200 KB | code + 年/半年/月次数 + 最近涨停日 |

**结论**：一年涨停数据存储成本极低（快照仅 ~2 MB，或直接复用现有日线缓存 60 MB 推导，无需额外存储）。

### 边界条件
- **ST 5% 涨跌停**：按名称识别，用 5% 判定
- **次新股上市首日**：无涨跌停限制，上市 5 日内不纳入统计
- **除权除息**：日线为不复权数据，涨停价按「昨收」计算时，除权日会失真 → 用除权日前后「实际涨停」需额外对齐；简化处理：除权日跳过涨停判定
- **未封板判定依赖当日最高/最低价**：日线数据含 high/low，可直接判定

### 交互
- 涨停板 / 跌停板 Tab 内分「封板 / 未封板」子 Tab
- 涨停板列表新增「年/半年/月涨停次数」三列
- 日期选择器（前 5 个交易日）

## 六、形态筛选

### 需求
- 新增「是否下载历史数据到本地」开关
- 新增「一年内涨停板次数排行」筛选条件

### 数据来源
- 历史数据：通达信 mootdx 日/周/月线
- 涨停次数：本地日线推导（同上）

### 计算规则
- **下载开关**：
  - 开启（默认）：扫描时拉取 K 线并写入本地缓存（`output/cache/v2/`）
  - 关闭：仅内存计算，不落盘（复用已缓存数据或临时拉取），扫描结束后不新增缓存
- **涨停次数排行筛选**：
  - 输入：涨停次数下限 N（如「近一年涨停 ≥ 3 次」）
  - 计算：每只股票近一年涨停次数（日线推导），作为附加过滤条件
  - 结果增加「年涨停次数」列，支持按该列排序

### 边界条件
- **下载开关关闭时**：若本地无缓存，需临时拉取（数据仍准确，只是不落盘）；历史涨停次数依赖日线，开关关闭时该筛选可能失效（提示用户开启下载）
- **涨停次数依赖 260 根日线**：若缓存不足，显示「数据不足」

### 交互
- 「附加筛选条件」区新增「下载历史数据」checkbox（默认勾选）
- 新增「近一年涨停次数 ≥ N」输入框
- 结果列表新增「年涨停次数」列，可排序

## 七、数据源汇总表

| 模块 | 数据源 | 计算 | 边界 |
|---|---|---|---|
| 连板天梯 | 涨停池 lbc + 同花顺 reason | 按高度分组 | ST 5%、次新无限制 |
| 跌停连板 | 本地日线 | 连续跌停天数 | 停牌跳过 |
| 龙虎榜 | datacenter 三张报表 | 净额=买-卖 | 非交易日空 |
| 题材热点 | 涨停池 + 同花顺 reason | 词频 ≥2 | reason 空跳过 |
| 周末新闻 | np-weblist 快讯 | 时间窗口过滤 | 节假日窗口漂移 |
| 未封板 | 本地日线 high/low | 触板未封 | 除权日失真 |
| 涨停次数 | 本地日线 | 涨停判定计数 | ST/次新/除权 |
| 下载开关 | mootdx + 本地缓存 | 落盘开关 | 无缓存时临时拉取 |

## 八、实施顺序（建议）

1. **数据层**：新增本地日线推导模块（涨停/跌停/未封板/连板/涨停次数判定）——所有历史统计的地基
2. **连板天梯**改造（4 字段 + 跌停连板）
3. **涨停/跌停板**改造（未封板子模块 + 涨停次数列 + 删除烂板）
4. **龙虎榜**详情页（席位 + 近 1 年明细 + 排序）
5. **题材热点**门槛（≥2 只）
6. **周末热点新闻**（时间窗口 + 节假日边界）
7. **形态筛选**（下载开关 + 涨停次数筛选）
8. 统一交互（前 5 交易日日期选择器 + 风格统一）

## 九、风险与缓解

| 风险 | 缓解 |
|---|---|
| 涨停池仅 10 天历史 | 历史统计全部走本地日线推导 |
| 跌停/炸板池近期为空 | 未封板/跌停连板走本地日线推导兜底 |
| ST 涨跌停 5% 判定 | 按名称识别 ST，用 5% 规则 |
| 除权日涨停价失真 | 不复权数据，除权日跳过涨停判定 |
| 东财限流 | 详情页按需查询 + 节流；列表页单次请求 |
| 下载开关关闭导致涨停次数失效 | 前端提示需开启下载 |
