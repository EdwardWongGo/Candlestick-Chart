# 用户使用说明 —— A股蜡烛图形态筛选工具

> 适用版本：master 分支（2026-08 起）
> 面向对象：测试用户 / 普通使用者。若你是开发者，另见根目录 `README.md`。

---

## 一、功能概述

本工具是一个 **A股（沪深京）蜡烛图形态筛选器**：它从行情服务器拉取股票的 K 线数据，按照经典的蜡烛图形态（锤子线、看涨吞没、看跌吞没等）自动筛选出「形态命中」的股票，并以 Web 页面直观展示结果，方便你做形态选股与研究。

**核心能力：**

| 能力 | 说明 |
|---|---|
| K 线数据同步 | 一键从服务器同步**日线 / 周线 / 月线**三个时间维度的全市场数据到本地 |
| 形态筛选 | 内置十余种蜡烛图形态，支持看涨 / 看跌方向、信号强度排序 |
| 多时间级别 | 日线、周线、月线可单独或组合筛选（权重不同） |
| 附加过滤 | 涨跌幅、放量倍数、价格区间、年线(MA250)上方、不含 ST 等 |
| 历史记录 | 筛选结果历史保存，可回看 / 继续筛选 / 导出 CSV 与 HTML 报告 |
| 形态自检 | 内置「形态引擎自检」，一键验证识别逻辑是否正确 |

**界面入口：** 启动后浏览器自动打开 `http://127.0.0.1:8000`。

## 二、快速开始

1. **启动程序**（二选一）：
   - 双击项目根目录的 **`启动筛选工具.bat`**（推荐，无需命令行）；
   - 或在命令行执行 `python run.py`。
2. 浏览器自动打开工具页面；若未自动打开，手动访问 `http://127.0.0.1:8000`。
3. 首次使用建议先做一次数据同步（见第三章），再点击「开始筛选」。
4. 关闭命令行窗口即可停止服务（程序退出）。

## 三、数据同步操作流程

> 数据同步的作用：把服务器的 K 线数据拉到本地（`data/` 目录），之后筛选**基于本地数据**，速度快、不依赖网络。**默认同步日、周、月三个时间维度**，也可按需配置。

### 3.1 界面同步步骤

1. 在左侧面板「**数据来源**」中选择「**🌐 服务器**」。
2. **服务器地址**：留空 = 使用内置默认服务器（推荐）；也可填写自定义服务器，格式 `主机:端口`，例如 `119.97.185.59:7709`。
3. **同步级别**：默认勾选「日线」「周线」「月线」三项（全选）。
4. 点击「**🔌 连接**」，等待进度条走完。
5. 出现「✅ 连接成功，同步 N 项」即完成，此时可点击「开始筛选」。

> 全市场（约 5000+ 只）× 三级别，同步约需**数分钟**；仅勾选日线则约需数十秒。同步中途不要关闭页面。

### 3.2 日线 / 周线 / 月线 说明

| 时间级别 | 一根 K 线代表 | 本地保存位置 | 同步根数 | 用途 |
|---|---|---|---|---|
| 日线 | 1 个交易日 | `data/daily/{代码}.csv` | 约 260 根（覆盖年线） | 常规短线形态 |
| 周线 | 1 个交易周 | `data/weekly/{代码}.csv` | 约 120 根 | 中期趋势形态 |
| 月线 | 1 个自然月 | `data/monthly/{代码}.csv` | 约 120 根 | 长期趋势形态 |

- 三个级别**默认全同步**，保证任意级别筛选都有本地数据。
- 每个代码一个 CSV 文件，列依次为：日期、开盘、最高、最低、收盘、成交量（前复权）。
- 同步完成后，`data/` 下会出现 `daily/`、`weekly/`、`monthly/` 三个子目录。

### 3.3 只同步部分级别（可选配置）

- 在「同步级别」处**取消勾选**不需要的级别即可，例如只勾「日线」→ 仅同步日线。
- 若三个级别**全部取消勾选**，程序会自动回退为默认三级别同步，保证数据完整。

### 3.4 同步与筛选的关系

- **同步级别**（数据来源面板的勾选）决定「拉到本地哪些数据」；
- **筛选级别**（筛选面板的「时间级别」chips）决定「按哪些级别做形态筛选」。
- 两者互相独立：筛选时若某个级别本地没有缓存，程序会**现场从服务器拉取并自动缓存**（速度较慢，但无需预先同步）。
- 建议：先三级别同步一次，之后筛选任何级别都走本地缓存，最快。

### 3.5 命令行方式（可选）

- 启动服务：`python run.py`（默认端口 8000）。
- 命令行批量扫描（基于本地缓存，需先同步数据）：
  ```
  python run.py --scan --full --tf daily,weekly,monthly --pattern hammer,bullish_engulfing
  ```
  完整参数见根目录 `README.md`。命令行模式不会触发数据同步；如需最新数据请先启动 Web 界面同步一次。

## 四、配置方式

### 4.1 服务器地址（界面可配）

- 默认：留空，程序自动从内置通达信服务器列表中选择可用服务器。
- 自定义：填写 `主机:端口`（如 `110.41.147.114:7709`），用于默认服务器不可用或公司内网有专用行情源的情况。

### 4.2 同步级别（界面 / 配置文件均可配）

- **界面配置（首选）**：数据来源 → 服务器 →「同步级别」勾选日/周/月。
- **配置文件配置**：编辑项目根目录 `config.py`，找到 `SYNC_TIMEFRAMES`：
  ```python
  SYNC_TIMEFRAMES = ["daily", "weekly", "monthly"]   # 默认三级别；可增删，如只留 ["daily"]
  ```
  修改后需**重启程序**生效。界面勾选优先级更高（界面传值会覆盖此默认值）。

### 4.3 其他常用配置（`config.py`）

| 配置项 | 含义 | 默认值 |
|---|---|---|
| `TIMEFRAMES` | 时间级别定义（日/周/月，含权重） | daily / weekly / monthly |
| `MIN_BARS` | 各级别最少 K 线根数（不足则无法算均线/形态） | 日 260 / 周月 120 |
| `KLINE_OFFSET` | 每次拉取 K 线根数 | 300 |
| `MA250_PERIOD` | 年线周期 | 250 |
| `PORT` | Web 端口（也可用 `--port` 参数） | 8000 |

### 4.4 数据与运行环境

- **依赖安装**（首次部署时）：`pip install -r requirements.txt`
- **数据目录** `data/`：
  - `daily/`、`weekly/`、`monthly/`：各级别 K 线缓存（CSV）；
  - `universe.csv`：全市场股票池（约 5000+ 只）；
  - `sync_meta.json`：最近一次同步时间记录（界面「上次同步」即读它）。
- **导出产物**：筛选结果导出 CSV（UTF-8 BOM，Excel 可直接打开）与自包含 HTML 报告。

## 五、常见问题（FAQ）

### 5.1 提示「连接失败，请检查网络或稍后重试」
- 检查本机网络是否可访问外网（行情源为公网服务器）。
- 稍等重试；若默认服务器不可用，可在「服务器地址」填写其他通达信服务器（见 4.1）。
- 内网 / 代理环境可能需要放行 `7709`（TCP，通达信）与 `443`（HTTPS，腾讯兜底）端口。

### 5.2 同步完成后 `data/` 下只有 `daily` 文件夹？
- 原因：同步时只勾选了「日线」（或程序收到的同步级别只有 daily）。
- 解决：在「同步级别」勾选「周线」「月线」后**重新点击「连接」**，即可生成 `weekly/`、`monthly/`。

### 5.3 周线 / 月线文件没有生成？
- 同 5.2：同步级别未包含周/月线。
- 或未做同步：此时在筛选面板选中「周线 / 月线」直接开始筛选，程序会自动拉取并缓存对应数据。

### 5.4 涨停板 / 题材热点 / 龙虎榜 / 周末热点为空？
- 这些数据依赖**盘后发布**：交易日盘中或周末查询当日数据可能为空，属正常。
- 程序已内置兜底：龙虎榜 / 周末热点自动取「最近一个已收盘交易日」的数据。
- 确认已同步数据后重试；若仍为空，多为行情源临时不可用，稍后重试。

### 5.5 启动时提示端口被占用 / 服务起不来？
- 8000 端口被其他程序占用时，改用其他端口启动：`python run.py --port 8001`，然后访问 `http://127.0.0.1:8001`。

### 5.6 某些股票没有数据 / 同步被跳过？
- **停牌股**在增量同步时无新增 K 线，会被跳过（属正常，不报错）。
- 新股 / 次新股历史根数不足 `MIN_BARS` 时，无法计算形态，属正常。

### 5.7 数据不是最新？
- 数据只更新到「最近一次同步」时刻。重新点击「🔌 连接」即可增量更新（只拉取新增 K 线，速度快）。

### 5.8 浏览器没有自动打开？
- 手动访问 `http://127.0.0.1:8000` 即可；确认程序仍在运行（命令行窗口未关闭）。

### 5.9 双击 `.bat` 闪退 / 报 ModuleNotFoundError？
- 说明依赖未安装：在命令行执行 `pip install -r requirements.txt` 后重试。
- 若使用虚拟环境，请先激活 venv 再运行 `python run.py`。

### 5.10 如何完全停止程序？
- 关闭启动时打开的命令行窗口（服务随之停止）；或在命令行按 `Ctrl+C`。
