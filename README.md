# A股量化分析工具

> 作者：HZQ

> 📖 **普通使用者请阅读《使用说明》：** [`使用说明.html`](使用说明.html)（双击打开，含环境准备、启动步骤、数据同步、常见问题排查）

一款面向 A 股市场的多功能量化分析工具，顶层可切换九大功能模块：

1. **形态筛选**：基于日本蜡烛图（K线）技术形态与成交量的多级别扫描（日/周/月线 + 跨级别共振）
2. **涨停板**：当日涨停股 + 涨停原因 + 首次封板时间（含「涨停打开」子项）
3. **跌停板**：当日跌停股 + 跌停原因 + 首次跌停时间（含「跌停打开」子项）
4. **连板天梯**：按连板数分组（首板/2板/3板/…N板），含涨停连板 / 跌停连板
5. **龙虎榜**：全市场龙虎榜 + 个股买卖席位 TOP5 + 机构动向
6. **市场分析**：指数实时行情 + 指数 K 线（上证/深成/创业板/科创50 等，日/周/月）
7. **题材热点**：题材板块热点与相关个股
8. **每日新闻**：每日财经要闻 / 市场资讯
9. **个股研报**：东财研报（标题/机构/评级/EPS/PDF）

结果以可视化列表呈现、可点击查看 K 线图（高亮形态位置）、可导出 CSV。

## 核心特性

- **形态识别**：内置 19 个常见蜡烛图形态（单根/双根/三根/多根），每个形态区分 **看涨 / 看跌** 方向
- **多级别扫描**：日线 / 周线 / 月线可单独或同时选择，扫描结果标注所属级别
- **跨级别共振**：同一股票在 ≥2 个级别出现同方向信号时自动标记「共振」，并加成内部信号分（结果表按涨跌幅展示与排序，信号分仅用于共振加成与历史兼容）
- **市场区分**：支持按 **上证 / 深证 / 北证 / 科创 / 创业** 多选筛选，**默认全选**（等价于不限），且至少保留一个
- **年线条件**：「最新股价在年线（MA250）之上」开关，可与市场条件、形态条件自由组合
- **文件导入**：数据来源支持「上传文件」（TXT/CSV/通达信 EBK），自动校验并提示成功/失败数，作为自定义股票池筛选
- **组合过滤**：形态之外，支持按**较前量**（本根量 ÷ 前一根量）、价格区间、涨跌幅、总市值/流通市值区间、近一年涨停次数、年线(MA250)、剔除 ST 组合过滤
- **结果缓存**：筛选结果自动缓存，切换功能后快速恢复上次结果；「重新加载」按钮可主动刷新数据
- **筛选报告**：一键生成自包含 HTML 报告（双击即可离线打开），含概览卡片、行业分布、概念题材分布、形态分布、结论与建议、全部信号明细；行业/题材**全部列出可搜索、点击行展开该分类下的个股**，明细表**可折叠、表头可排序**
- **数据展示**：列表含代码/名称/板块/级别/形态/**涨跌幅（个股最新交易日）**/**级别涨跌幅（周线=本周、月线=本月）**/较前量/现价/总市值/流通市值/近一年涨停次数/共振等字段，点击行弹出 K 线图并高亮形态；日/周/月线显示**上市以来全部历史**（前复权，高分红股自动切后复权），支持全屏、上一只/下一只、右侧结果栏切换（**侧栏顺序与主表当前排序一致**）；**双击某根 K 线可查看该日分时**（数据源仅保留最近 5 个交易日）；tooltip 显示开高低收/**当日涨跌幅**/成交量，拖动缩放条可**统计任意区间涨跌幅与振幅**
- **视图与排序**：默认按**最新交易日涨跌幅**降序，点击任一表头可切换排序列与升降序；支持「按股票分组」把同股多级别折叠成一行（分组时分页栏显示「共 N 只（M 条信号）」）
- **分页与导出**：结果分页展示（15/30/50/100/200 条/页）、一键导出 CSV（UTF-8 BOM，Excel 直接打开）、一键生成 HTML 报告
- **进度与停止**：扫描中筛选项置灰禁用 + 实时进度条（含预估剩余时间）+「停止筛选」随时中断
- **错误日志**：筛选失败自动落盘 errlog（output/logs/），便于排查
- **测试入口**：内置「形态引擎自检」按钮，一键运行 17 项合成数据用例验证筛选逻辑
- **数据来源**：K 线可取『通达信 / 腾讯 / 新浪 / 上传文件』，**筛选与同步共用同一个数据源下拉**（缓存已有数据时优先读本地，缺失才按所选源拉取）；K 线本地缓存落盘 `data/`，日终批量扫描为主，预留实时监控扩展

## 市场事件模块

顶层共 9 个功能 Tab，除「形态筛选」外，其余 8 个覆盖市场事件、分析、资讯与研报：

| 模块 | 数据来源 | 核心字段 |
|------|---------|---------|
| **涨停板** | 东财涨停池 `wz.ztzt` + 同花顺 getharden | 涨停原因、首次封板时间、连板数、炸板次数、封单额、行业 |
| **跌停板** | 东财跌停池 `wz.dtzt` | 跌停原因、首次跌停时间、封单额 |
| **连板天梯** | 涨停池 `lbc` 派生 | 按连板数分组：首板 / 2板 / 3板 / … N板（涨停连板 / 跌停连板） |
| **龙虎榜** | 东财 datacenter | 上榜原因、净买额、换手；点击查看买卖席位 TOP5 + 机构动向 |
| **市场分析** | 腾讯财经 + 东财（北证50） | 指数实时行情、指数 K 线（上证/深成/创业板/科创50 等） |
| **题材热点** | 公开财经热点接口 | 题材板块热点、相关个股 |
| **每日新闻** | 财经资讯聚合 | 每日财经要闻 / 市场资讯 |
| **个股研报** | 东财研报公开接口 | 标题、机构、评级、EPS 预测、PDF 链接 |

> 涨停「打开」（即烂板：涨停后炸板回封）并入「涨停板」模块的「涨停打开」子项查看。

### 涨停原因与涨停时间

- **涨停原因**：同花顺 `getharden` 接口人工运营的题材归因 tags（如"间接参股光芯片+磷化铟"）
- **首次封板时间**：东财涨停池 `fbt` 字段（如 `92500` = 09:25:00）
- **连板数**：`lbc` 字段；**炸板次数**：`zbc` 字段（>0 即"烂板"）
- **交易日自动校准**：东财对非交易日返回最近交易日数据，响应中 `qdate` 字段为真实交易日

> 注：东财接口有风控（每秒 ≤5 次），本模块内置串行节流；涨停/跌停/龙虎榜均为单次请求，无批量循环，安全。

## 快速开始

### 方式一：双击启动（推荐，无需命令行）

双击项目根目录下的 **`启动筛选工具.bat`**，即可自动启动服务并打开浏览器。

> 该脚本使用 `%~dp0` 定位项目目录（不依赖中文路径编码），优先调用内置 Python 环境，
> 若环境不存在则回退到系统 `python`。服务以 `pythonw.exe` 后台运行，
> **关闭启动时的命令行窗口不会停止服务**；服务输出写入 `服务日志.log`，启动过程写入 `启动日志.log`。
> 启动前会用 `check_port.py` 探测 8000 端口，已在运行则直接打开浏览器。

**停止服务**：双击 **`停止筛选工具.bat`**（调用 `stop_service.py`），或关闭 `pythonw.exe` 进程。

> 旧版脚本用 `start /b` 启动，服务与 cmd 窗口同生共死；现已改为独立进程，
> 避免「关掉启动窗口后台任务被一起杀掉」。

### 方式二：命令行启动

```bash
# 1. 安装依赖（建议虚拟环境）
pip install -r requirements.txt
#   依赖：mootdx(通达信) requests pandas numpy flask

# 2. 启动 Web 服务（自动打开浏览器）
python run.py                 # 打开 http://127.0.0.1:8000
python run.py --no-browser    # 不自动打开浏览器

# 3. 或命令行日终批量扫描（适合定时任务）
python run.py --scan --tf daily,weekly
python run.py --scan --full --tf daily --pattern hammer,bullish_engulfing --volume-min 1.5
python run.py --scan --tf daily --markets kcb,cyb --ma250
```

> 首次运行 mootdx 会生成 `~/.mootdx/config.json` 并自动选择最快服务器。
> 通达信为 TCP 协议（端口 7709），需可访问国内网络；海外环境建议配置代理。

## 蜡烛图形态库

共 19 个形态，按所需 K 线根数分组：

### 单根形态（1 根）

| Key | 名称 | 方向 | 识别要点 |
|-----|------|------|----------|
| `hammer` | 锤子线 | 看涨 | 下跌后，下影 ≥ 2×实体，上影很小 |
| `inverted_hammer` | 倒锤子线 | 看涨 | 下跌后，上影 ≥ 2×实体，下影很小 |
| `hanging_man` | 上吊线 | 看跌 | 上涨后，下影 ≥ 2×实体（锤子线的顶部形态） |
| `shooting_star` | 射击之星 | 看跌 | 上涨后，上影 ≥ 2×实体，冲高回落 |
| `doji` | 十字星 | 双向 | 实体 ≤ 0.1×振幅，方向依前期趋势；「十字星数量」可设连续 1-6 根（默认 1），无验证子选项 |
| `dragonfly_doji` | 蜻蜓十字 | 看涨 | T 字线，长下影探底回升 |
| `gravestone_doji` | 墓碑十字 | 看跌 | 倒 T 字线，长上影冲高回落 |

### 双根形态（2 根）

| Key | 名称 | 方向 | 识别要点 |
|-----|------|------|----------|
| `bullish_engulfing` | 看涨吞没 | 看涨 | 阳线实体完全吞没前一根阴线 |
| `bearish_engulfing` | 看跌吞没 | 看跌 | 阴线实体完全吞没前一根阳线 |
| `piercing` | 刺透形态 | 看涨 | 下跌后低开高走，阳线深入前阴线实体上半部 |
| `dark_cloud_cover` | 乌云盖顶 | 看跌 | 上涨后高开低走，阴线深入前阳线实体下半部 |
| `bullish_harami` | 看涨孕线 | 看涨 | 大阴线后小阳线被完全包含 |
| `bearish_harami` | 看跌孕线 | 看跌 | 大阳线后小阴线被完全包含 |

### 三根形态（3 根）

| Key | 名称 | 方向 | 识别要点 |
|-----|------|------|----------|
| `morning_star` | 启明星 | 看涨 | 大阴线 + 星线 + 大阳线，收回第一根实体一半以上 |
| `evening_star` | 黄昏星 | 看跌 | 大阳线 + 星线 + 大阴线，跌破第一根实体一半 |
| `three_white_soldiers` | 三个白武士 | 看涨 | 三根连续大阳线，逐根高开，收于最高附近 |
| `three_black_crows` | 三只乌鸦 | 看跌 | 三根连续大阴线，逐根低开，收于最低附近 |

### 多根形态（参数化 / 趋势）

| Key | 名称 | 方向 | 识别要点 |
|-----|------|------|----------|
| `single_yang_no_break` | 单阳不破 | 看涨 | 攻击性长阳（当日涨幅≥5%，最好涨停）后 6~8 根 K 线横向盘整，所有最低价均未跌破该阳线最低价 |
| `yang_up_no_break` | 阳上不破 | 看涨 | 无上影线大阳线（收盘=最高、涨幅≥5%）后，3~8 根 K 线收盘价站稳其收盘价之上，且不超过其 1.1/1.2/1.3 倍（按主板/创业板科创板/北交所涨停幅度自动判断） |
| `suspected_main_rise` | 疑似主升 | 看涨 | 最近 3 根 K 线收盘价均未跌破各自 MA5（沿 5 周期均线强势上行） |

> 说明：`单阳不破`、`疑似主升` **无「验证」子选项、无参数**，判定规则固定。`单阳不破` 按雪球定义：基准阳线为「攻击性长阳」（当日涨幅≥5%），其后 6~8 根 K 线最低价均未跌破该阳线最低价，通常第 6 根进入启动期。
>
> `十字星` 为参数化形态：**无「验证」子选项**，新增「十字星数量」参数（连续 1-6 根，默认 1），判定时要求最近 N 根均为十字星，连续根数越多信号越强。
>
> `阳上不破` 为单阳不破变种：**无「验证」子选项、无参数**。设无上影线大阳线收盘价为 a，自动扫描其后 3~8 根窗口，要求窗口内每根收盘价 x 满足 `a ≤ x ≤ a×b`（b 按板块自动取 1.1 主板 / 1.2 创业板科创板 / 1.3 北交所），取最近成立的窗口命中。

## 核心形态识别算法逻辑

### 1. 蜡烛几何量定义（`app/models.py`）

对任意一根 K 线，先计算四个几何量：

```
body         = |close - open|              # 实体长度
upper_shadow = high - max(open, close)     # 上影线
lower_shadow = min(open, close) - low      # 下影线
total_range  = high - low                  # 全振幅
```

所有形态判断都建立在这四个量之上，纯几何、无 IO，便于单元测试。

### 2. 前期趋势判断（`app/patterns/base.py`）

反转形态（锤子线、吞没、启明星等）要求「形态出现之前存在相反趋势」，
否则信号无意义。采用**线性回归斜率**度量形态前 N 根（默认 20 根）收盘价的趋势：

```
slope_pct = (Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²) * (n-1) / ȳ
slope_pct >  +0.01  → 上涨趋势 (up)
slope_pct <  -0.01  → 下跌趋势 (down)
否则               → 无趋势（不触发反转形态）
```

### 3. 信号强度评分（0-100）

每命中一个形态，强度 = **基础可靠性 + 量能确认 + 趋势加成**，封顶 100：

```
strength = base_score           # 形态固有可靠性（如吞没 68、启明星 78、锤子 60）
         + 放量加成             # 量比≥1.2 +4 / ≥1.5 +8 / ≥2.0 +12
         + 趋势加成             # 存在明确反向趋势 +4
```

其中 `base_score` 还随形态「质量」浮动（如吞没形态阳线实体相对前阴线越大分越高）。

### 4. 量能确认（较前量 / 放量倍数）

```
较前量 = 本根成交量 / 前一根成交量
```

「放量倍数 ≥ x」即要求 **本根成交量 ≥ 前一根成交量 × x**，与“相对自己的上一根有没有放大”直接对应。

> 早期版本用「本根 / 近 20 根均量」。前一根缩量时，本根只要略高于均量就会被判成放量——
> 全市场实测（阈值 ≥2）旧口径命中 277 条，其中 198 条（71%）并没有比前一根放大，
> 同时也会漏掉“对前一根真放量、但对均量不到 2 倍”的股票。现已统一改为较前量口径。
>
> 例外：**形态强度打分里的「放量加成」仍用对 20 日均量的倍数**（≥2.0 +12 / ≥1.5 +8 / ≥1.2 +4），
> 那是衡量“量能相对常态有多活跃”，与作为筛选门槛的较前量性质不同。

### 5. 支撑 / 阻力 & 相对位置

```
support     = 形态前 60 根 K 线的最低点
resistance  = 形态前 60 根 K 线的最高点
相对位置     = (close - support) / (resistance - support)   # 0=贴近支撑, 1=贴近阻力
```

用于「接近支撑 / 接近阻力」过滤（阈值见 `config.py`）。

### 6. 形态扫描策略

- 形态判断**基于最近连续交易日窗口**（非全周期扫描）：形态必须恰好完成于最近 N 根 K 线内
  - 单根形态看最近 1 根，双根看最近 2 根，三根（如启明星）看最近 3 根
- **验证子选项**：勾选「验证」后，形态在原所需根数上追加 1 天验证日（如启明星 3 天 → 4 天），
  仅当验证日确认形态方向（看涨形态验证日收涨、看跌形态验证日收跌）时才命中；
  「单阳不破」「阳上不破」「疑似主升」「十字星」为固定规则/参数化形态，**不提供验证子选项**
- 命中结果记录形态涉及的 K 线下标 `candle_indexes`（含验证日），供前端图上高亮

## 多级别筛选流程

```
┌─────────────────────────────────────────────────────────┐
│ 1. 加载股票池（统一本地数据源）                            │
│    读本地 universe.csv（全市场列表，缺失则首次拉取并缓存）   │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 1.5 可选：数据来源选「服务器」时，先增量同步最新行情到本地    │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 2. 逐级别 × 逐股票 读取 K 线（本地缓存，缺失拉取并落盘）     │
│    daily(日) / weekly(周) / monthly(月) 独立读取           │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 3. 每个级别独立跑形态识别 detect_patterns()               │
│    → 得到该股票该级别的 PatternMatch 列表                  │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 4. 附加条件过滤（可组合）                                  │
│    较前量 / 价格区间 / 涨跌幅 / 涨停次数 / 市值 / 剔除ST    │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 4.5 命中股票画像补全（只对命中股票，避免全市场请求）         │
│    行业归属 industry.py / 总市值·流通市值 腾讯快照           │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 5. 跨级别共振确认 apply_resonance()                       │
│    同股票同方向在 ≥2 个级别命中 → 标记共振 + 强度加成        │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 6. 排序输出（默认按最新涨跌幅，可切任意列）+ 列表 + 导出/报告   │
└─────────────────────────────────────────────────────────┘
```

### 共振规则（`config.py` 可调）

- `RESONANCE_MIN_LEVELS = 2`：同一股票在 ≥2 个所选级别出现**同方向**信号，判定为共振
- `RESONANCE_BONUS = 15`：共振时每条命中强度 +15（封顶 100）
- 级别权重：日线 ×1.0、周线 ×1.15、月线 ×1.30（大级别信号更显著）

示例：贵州茅台「日线看涨吞没 + 周线看涨吞没」→ 标记「共振·日/周」，看涨信号更可信。

### 文件导入格式

支持 **TXT / CSV / 通达信 EBK** 三种格式，每行一个代码，也支持逗号/分号/空格/制表符分隔，自动忽略 `.SH/.SZ` 后缀。

**1. 普通 TXT / CSV**（6 位真实代码）：

```
600519
300750,688981
002594
000858
```

**2. 通达信 EBK**（市场标识 + 6 位代码，共 7 位）：

通达信导出的 EBK 文件在代码前加了 1 位市场标识，导入时自动剥离：

| EBK 值 | 市场标识 | 实际代码 | 板块 |
|---------|---------|---------|------|
| `1600097` | 1 = 上证 | `600097` | 上证 |
| `0002159` | 0 = 深证 | `002159` | 深证 |
| `1688981` | 1 = 上证 | `688981` | 科创 |
| `2920808` | 2 = 北证 | `920808` | 北证 |

> 市场标识 `0=深证 1=上证 2=北证`，剥离后按 6 位代码重新判定板块，因此即使标识写错也不影响最终分类。

导入后自动校验：合法的 6 位 A 股代码计入「成功」，其余计入「失败」并展示失败样例。
导入成功的代码作为**自定义股票池**，可继续叠加市场板块、年线、蜡烛图形态等条件筛选。

4. **蜡烛图形态**：按「看涨/看跌/中性」分组，支持全选/清空；部分形态带「验证」子选项与参数 N
5. **附加条件**：年线(MA250)开关、近一年涨停次数、较前量、价格区间、涨跌幅、市值区间、剔除 ST
6. **开始筛选**：提交后台任务，扫描中筛选项置灰禁用 + 实时进度条（含预估剩余时间）+「停止筛选」可随时中断；下方「形态引擎自检」一键验证识别逻辑

### 右侧结果列表

- 字段：代码、名称、板块、级别、形态、**涨跌幅（个股最新交易日）**、**级别涨跌幅（周线=本周、月线=本月）**、较前量、现价、总市值/流通市值、近一年涨停次数、共振标记

- **重新加载**：点击「🔄 重新加载」用上次条件重新执行筛选并刷新数据；切换功能 Tab 回来时结果自动保留，无需重新计算
- **历史筛选结果**：每次筛选（命中 > 0）完成后自动缓存到本地，顶部「🕘 历史筛选结果」栏列出所有历史记录；点击加载后可继续排序/共振筛选/导出/生成报告。**加载历史结果时按「范围锁定」处理**：
  - 时间级别、市场板块、形态：**只有该次筛选选过的项可操作**，没选过的置灰；选过的可自由取消（级别/板块至少留一个）
  - 数值条件（较前量、价格、市值等）：**只有原来填了值的锁定**，空着的仍可编辑，便于在原条件上继续收紧
  - 年线、剔除 ST：原来勾上的锁定，没勾的可追加
  - 支持单条删除（✕）与批量删除（勾选 + 全选），删除后立即从界面移除并同步清理本地缓存文件
- **零命中处理**：当某次筛选命中 0 只股票时，不写入结果缓存、不写入历史记录、不展示在结果列表（仅提示"无符合条件"）
- **分页**：底部支持上一页/下一页、数字页码导航（含省略号折叠）、每页条数（15/30/50/100/200）
- **排序**：默认按**涨跌幅降序**，点击任一表头切换列与升降序；「按股票分组」时同股多级别折叠成一行
- **共振筛选**：勾选「仅看共振」只看多级别共振信号
- **返回 / 清空**：解除历史锁定并**把筛选条件重置为默认**（级别与板块全选、形态清空、数值清空、剔除 ST 恢复勾选）
- **导出 CSV**：UTF-8 BOM，Excel 直接打开；**生成报告**：一键生成自包含 HTML 报告（见下节）

### 服务器数据同步

数据来源选择「服务器」后，可连接数据服务器（通达信/腾讯/新浪/自定义地址）把最新 K 线**增量同步**到本地缓存（本地已有则仅拉取最近几根对比追加，本地缺失则全量拉取），并记录同步时间显示在「上次同步」处。

- 增量同步避免重复下载历史数据，全市场场景下单日流量可降低约百倍
- 停牌股增量拉取无新 bar 属正常，自动跳过
- 同步状态可通过 `GET /api/sync/status` 查询，或 `POST /api/sync` 手动触发

### K线图弹窗

- 点击结果行，弹出该股票的 K 线图
- 图表包含：蜡烛图（涨红跌绿，符合 A 股配色）、MA5/10/20/60、成交量副图
- **形态高亮**：命中形态的 K 线区域用半透明色块 + 边框高亮，弹窗顶部图例列出该级别命中的全部形态
- 支持缩放/平移（鼠标滚轮 + 底部滑块）

## 数据来源与更新频率

### 数据源

| 数据 | 来源 | 协议 | 说明 |
|------|------|------|------|
| 日/周/月线 K 线 | **通达信 mootdx** | TCP 7709 | 不封 IP、无需鉴权，主数据源 |
| 日/周/月线 K 线（兜底） | **腾讯财经 / 新浪财经** | HTTPS | 通达信不可达或被拒时自动切换；腾讯路径为 `newfqkline`（旧 `fqkline` 已被 WAF 拦死） |
| 股票名称/现价/市值 | 腾讯快照 `qt.gtimg.cn` | HTTP | 批量快照（60 只/批），不封 IP；字段 44=流通市值、45=总市值（亿元） |
| 全市场股票列表 | 通达信 mootdx | TCP | 沪深 A 股约 5000 只 |
| 行业归属 | 东财 `push2` ulist（`f100`） | HTTPS | 仅查命中股票，7 天缓存 |
| 概念题材 | 东财概念板块 + 通达信 `block_gn.dat` + `themes.json` | HTTPS / TCP / 本地 | 三源合并约 537 个题材，7 天缓存 |
| 全量历史 K 线（看图） | 腾讯 `newfqkline` | HTTPS | 分段拉上市至今（每段 800 根），前复权（出现负价时整只切后复权） |

### 请求保护（防止打爆数据源）

| 机制 | 参数 | 作用 |
|---|---|---|
| 全局限流 | 2400 次 / 60 秒（40 次/秒） | 所有外部请求（通达信/腾讯/新浪/快照/分时/板块）统一过 `_throttle()` 滑动窗口，超限阻塞等待 |
| 通达信熔断 | 连续失败 3 次 → 降级 5 分钟 | K 线接口被拒时不再逐只白试，直接走腾讯兜底（此前全市场同步白试 1.5 万次，CPU 打到 304%） |
| 复权口径校验 | 同日期收盘价差异 > 0.5% | 判定换了复权基准（通达信不复权 vs 腾讯前复权），自动改全量覆盖，避免两套价格基准拼进同一 CSV |
| 增量窗口 | 30 根 | 覆盖长假与多日未开工具；窗口接不上缓存尾时改拉全量，避免日期断层导致形态误判 |

> 熔断状态与同步进度可通过 `GET /api/sync/status` 查看（`tdx_degraded` / `tdx_retry_in` / `repaired` 字段）。

### 更新频率

- **日终批量扫描（主）**：每个交易日收盘后（约 15:00 之后）运行一次，扫描当日全市场
  - 日线为完整交易日数据
  - 周线在周五收盘后完整，月线在月末完整（`INCLUDE_FORMING_BAR` 可控制是否纳入未收盘的周/月 K 线）
- **本地缓存**：K 线落盘到 `data/{daily|weekly|monthly}/`（`{code}.csv`），同周期内重复扫描直接读缓存，减少重复拉取
- **命令行定时任务示例**（Windows 任务计划 / Linux crontab）：
  ```bash
  # 每交易日 15:30 全市场日线扫描
  python run.py --scan --full --tf daily --volume-min 1.5 --sort-by strength
  ```
