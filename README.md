# A股量化分析工具

> 作者：HZQ

> 📖 **普通使用者请阅读《使用说明》：** [`使用说明.html`](使用说明.html)（双击打开，含环境准备、启动步骤、数据同步、常见问题排查）

一款面向 A 股市场的多功能量化分析工具，顶层可切换六大功能模块：

1. **形态筛选**：基于日本蜡烛图（K线）技术形态与成交量的多级别扫描（日/周/月线 + 跨级别共振）
2. **涨停板**：当日涨停股 + 涨停原因 + 首次封板时间
3. **跌停板**：当日跌停股 + 跌停原因 + 首次跌停时间
4. **烂板**：涨停后炸板（含首次上板时间、炸板次数、最终是否封板）
5. **连板天梯**：按连板数分组（首板/2板/3板/…N板）
6. **龙虎榜**：全市场龙虎榜 + 个股买卖席位 TOP5 + 机构动向

结果以可视化列表呈现、可点击查看 K 线图（高亮形态位置）、可导出 CSV。

## 核心特性

- **形态识别**：内置 17 个常见蜡烛图形态（单根/双根/三根），每个形态区分 **看涨 / 看跌** 方向
- **多级别扫描**：日线 / 周线 / 月线可单独或同时选择，扫描结果标注所属级别
- **跨级别共振**：同一股票在 ≥2 个级别出现同方向信号时自动标记「共振」，并加成信号强度
- **市场区分**：支持按 **上证 / 深证 / 北证 / 科创 / 创业** 单选或多选筛选（默认不限）
- **年线条件**：新增「最新股价在年线（MA250）之上」开关，可与市场条件、形态条件自由组合
- **文件导入**：导入 TXT/CSV 股票代码文件，自动校验并提示成功/失败数，作为自定义股票池筛选
- **组合过滤**：形态之外，支持按放量倍数、价格区间、涨跌幅、近一年涨停次数、年线(MA250)、剔除 ST 组合过滤
- **结果缓存**：筛选结果自动缓存，切换功能后快速恢复上次结果；「重新加载」按钮可主动刷新数据
- **数据展示**：列表含代码/名称/板块/级别/形态/方向/日期等字段，点击行弹出 K 线图并高亮形态
- **分页与导出**：结果分页展示、按信号强度或时间排序、一键导出 CSV（UTF-8 BOM）
- **进度与停止**：扫描中筛选项置灰禁用 + 实时进度条（含预估剩余时间）+「停止筛选」随时中断
- **错误日志**：筛选失败自动落盘 errlog（output/logs/），便于排查
- **测试入口**：内置「形态引擎自检」按钮，一键运行 13 项合成数据用例验证筛选逻辑
- **数据来源**：通达信（mootdx）日/周/月线，日终批量扫描为主，预留实时监控扩展

## 市场事件模块

顶层 6 个功能 Tab，除「形态筛选」外，其余 5 个参考券商 App 实现（数据来自东财涨跌停池 + 同花顺涨停原因 + 东财龙虎榜）：

| 模块 | 数据来源 | 核心字段 |
|------|---------|---------|
| **涨停板** | 东财涨停池 `wz.ztzt` + 同花顺 getharden | 涨停原因、首次封板时间、连板数、炸板次数、封单额、行业 |
| **跌停板** | 东财跌停池 `wz.dtzt` | 跌停原因、首次跌停时间、封单额 |
| **烂板** | 涨停池中 `zbc>0`（炸板后回封） | 首次上板时间、炸板次数、最终是否封板、涨停原因 |
| **连板天梯** | 涨停池 `lbc` 派生 | 按连板数分组：首板 / 2板 / 3板 / … N板 |
| **龙虎榜** | 东财 datacenter | 上榜原因、净买额、换手；点击查看买卖席位 TOP5 + 机构动向 |

### 涨停原因与涨停时间

- **涨停原因**：同花顺 `getharden` 接口人工运营的题材归因 tags（如"间接参股光芯片+磷化铟"）
- **首次封板时间**：东财涨停池 `fbt` 字段（如 `92500` = 09:25:00）
- **连板数**：`lbc` 字段；**炸板次数**：`zbc` 字段（>0 即"烂板"）
- **交易日自动校准**：东财对非交易日返回最近交易日数据，响应中 `qdate` 字段为真实交易日

> 注：东财接口有风控（每秒 ≤5 次），本模块内置串行节流；涨停/跌停/龙虎榜均为单次请求，无批量循环，安全。

## 快速开始

### 方式一：双击启动（推荐，无需命令行）

双击项目根目录下的 **`启动筛选工具.bat`**，即可自动启动服务并打开浏览器。

> 该脚本使用 `%~dp0` 定位项目目录（不依赖中文路径编码），优先调用内置 Python 环境，
> 若环境不存在则回退到系统 `python`。启动后自动打开 `http://127.0.0.1:8000`，
> 关闭命令行窗口即停止服务。

### 方式二：命令行启动

```bash
# 1. 安装依赖（建议虚拟环境）
pip install -r requirements.txt
#   依赖：mootdx(通达信) requests pandas numpy flask

# 2. 启动 Web 服务（自动打开浏览器）
python run.py                 # 打开 http://127.0.0.1:8000
python run.py --no-browser    # 不自动打开浏览器

# 3. 或命令行日终批量扫描（适合定时任务）
python run.py --scan --tf daily,weekly
python run.py --scan --full --tf daily --pattern hammer,bullish_engulfing --volume-min 1.5
python run.py --scan --tf daily --markets kcb,cyb --ma250
```

> 首次运行 mootdx 会生成 `~/.mootdx/config.json` 并自动选择最快服务器。
> 通达信为 TCP 协议（端口 7709），需可访问国内网络；海外环境建议配置代理。

## 核心形态识别算法逻辑

### 1. 蜡烛几何量定义（`app/models.py`）

对任意一根 K 线，先计算四个几何量：

```
body         = |close - open|              # 实体长度
upper_shadow = high - max(open, close)     # 上影线
lower_shadow = min(open, close) - low      # 下影线
total_range  = high - low                  # 全振幅
```

所有形态判断都建立在这四个量之上，纯几何、无 IO，便于单元测试。

### 2. 前期趋势判断（`app/patterns/base.py`）

反转形态（锤子线、吞没、启明星等）要求「形态出现之前存在相反趋势」，
否则信号无意义。采用**线性回归斜率**度量形态前 N 根（默认 20 根）收盘价的趋势：

```
slope_pct = (Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²) * (n-1) / ȳ
slope_pct >  +0.01  → 上涨趋势 (up)
slope_pct <  -0.01  → 下跌趋势 (down)
否则               → 无趋势（不触发反转形态）
```

### 3. 信号强度评分（0-100）

每命中一个形态，强度 = **基础可靠性 + 量能确认 + 趋势加成**，封顶 100：

```
strength = base_score           # 形态固有可靠性（如吞没 68、启明星 78、锤子 60）
         + 放量加成             # 量比≥1.2 +4 / ≥1.5 +8 / ≥2.0 +12
         + 趋势加成             # 存在明确反向趋势 +4
```

其中 `base_score` 还随形态「质量」浮动（如吞没形态阳线实体相对前阴线越大分越高）。

### 4. 量能确认（放量倍数）

```
放量倍数 = 当日成交量 / 近 20 根均量
```

看涨形态放量越明显、突破越可靠；该倍数同时作为可选过滤条件与结果展示字段。

### 5. 支撑 / 阻力 & 相对位置

```
support     = 形态前 60 根 K 线的最低点
resistance  = 形态前 60 根 K 线的最高点
相对位置     = (close - support) / (resistance - support)   # 0=贴近支撑, 1=贴近阻力
```

用于「接近支撑 / 接近阻力」过滤（阈值见 `config.py`）。

### 6. 形态扫描策略

- 形态判断**基于最近连续交易日窗口**（非全周期扫描）：形态必须恰好完成于最近 N 根 K 线内
  - 单根形态看最近 1 根，双根看最近 2 根，三根（如启明星）看最近 3 根
- **验证子选项**：勾选「验证」后，形态在原所需根数上追加 1 天验证日（如启明星 3 天 → 4 天），
  仅当验证日确认形态方向（看涨形态验证日收涨、看跌形态验证日收跌）时才命中
- 命中结果记录形态涉及的 K 线下标 `candle_indexes`（含验证日），供前端图上高亮

## 多级别筛选流程

```
┌─────────────────────────────────────────────────────────┐
│ 1. 加载股票池（统一本地数据源）                            │
│    读本地 universe.csv（全市场列表，缺失则首次拉取并缓存）   │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 1.5 可选：同步服务器数据（勾选后先把最新行情增量同步到本地）  │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 2. 逐级别 × 逐股票 读取 K 线（本地缓存，缺失拉取并落盘）     │
│    daily(日) / weekly(周) / monthly(月) 独立读取           │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 3. 每个级别独立跑形态识别 detect_patterns()               │
│    → 得到该股票该级别的 PatternMatch 列表                  │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 4. 附加条件过滤（可组合）                                  │
│    放量倍数 / 价格区间 / 涨跌幅 / 近一年涨停次数 / 剔除ST     │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 5. 跨级别共振确认 apply_resonance()                       │
│    同股票同方向在 ≥2 个级别命中 → 标记共振 + 强度加成        │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│ 6. 排序输出（按信号强度 / 时间）+ 列表展示 + CSV 导出        │
└─────────────────────────────────────────────────────────┘
```

### 共振规则（`config.py` 可调）

- `RESONANCE_MIN_LEVELS = 2`：同一股票在 ≥2 个所选级别出现**同方向**信号，判定为共振
- `RESONANCE_BONUS = 15`：共振时每条命中强度 +15（封顶 100）
- 级别权重：日线 ×1.0、周线 ×1.15、月线 ×1.30（大级别信号更显著）

示例：贵州茅台「日线看涨吞没 + 周线看涨吞没」→ 标记「共振·日/周」，看涨信号更可信。

## 筛选条件说明

| 条件 | 参数 | 说明 |
|------|------|------|
| 市场板块 | `markets` | 上证/深证/北证/科创/创业，可多选（空 = 不限） |

| 剔除 ST | `exclude_st` | 默认开启 |
| 排序 | `sort_by` | 按信号强度 / 按出现时间 / 按涨停次数 |

| 创业 | 300 / 301 |

### 文件导入格式

支持 **TXT / CSV / 通达信 EBK** 三种格式，每行一个代码，也支持逗号/分号/空格/制表符分隔，自动忽略 `.SH/.SZ` 后缀。

**1. 普通 TXT / CSV**（6 位真实代码）：

```
600519
300750,688981
002594
000858
```

**2. 通达信 EBK**（市场标识 + 6 位代码，共 7 位）：

通达信导出的 EBK 文件在代码前加了 1 位市场标识，导入时自动剥离：

| EBK 值 | 市场标识 | 实际代码 | 板块 |
|---------|---------|---------|------|
| `1600097` | 1 = 上证 | `600097` | 上证 |
| `0002159` | 0 = 深证 | `002159` | 深证 |
| `1688981` | 1 = 上证 | `688981` | 科创 |
| `2920808` | 2 = 北证 | `920808` | 北证 |

> 市场标识 `0=深证 1=上证 2=北证`，剥离后按 6 位代码重新判定板块，因此即使标识写错也不影响最终分类。

导入后自动校验：合法的 6 位 A 股代码计入「成功」，其余计入「失败」并展示失败样例。
导入成功的代码作为**自定义股票池**，可继续叠加市场板块、年线、蜡烛图形态等条件筛选。

## 界面交互说明

### 左侧筛选面板

1. **时间级别**：点击芯片切换日线/周线/月线（可多选）
2. **市场板块**：上证/深证/北证/科创/创业芯片（可多选，默认不限）
3. **自定义股票池**：点击「导入 TXT/CSV/EBK」选择文件，自动校验并显示成功/失败数
4. **蜡烛图形态**：按「看涨/看跌/中性」分组，支持全选/清空
5. **附加条件**：年线(MA250)开关、同步服务器数据开关、近一年涨停次数、放量倍数、价格区间、涨跌幅、剔除 ST
6. **开始筛选**：提交后台任务，扫描中筛选项置灰禁用 + 实时进度条（含预估剩余时间）+「停止筛选」可随时中断；下方「形态引擎自检」一键验证识别逻辑

### 右侧结果列表

- 字段：代码、名称、板块、级别、形态、方向、出现日期、信号强度、放量、现价、涨跌幅、近一年涨停次数、共振标记
- **统计信息**：顶部展示总样本数、符合条件数（行数/股票数）、年线上数量、看涨/看跌、共振、样本市场分布
- **重新加载**：点击「🔄 重新加载」用上次条件重新执行筛选并刷新数据；切换功能 Tab 回来时结果自动保留，无需重新计算
- **历史筛选结果**：每次筛选（命中 > 0）完成后结果自动缓存到本地，顶部「🕘 历史筛选结果」栏列出所有历史记录；点击即可加载该结果并继续排序/共振筛选/导出/生成报告等操作；支持单条删除（✕）与批量删除（勾选 + 全选），删除后立即从界面移除并同步清理本地缓存文件
- **零命中处理**：当某次筛选命中 0 只股票时，不写入结果缓存、不写入历史记录、不展示在结果列表（仅提示"无符合条件"）
- **分页**：底部支持上一页/下一页、每页条数（20/50/100）
- **排序**：点击「信号强度」表头切换升降序，或切换排序方式下拉框
- **共振筛选**：勾选「仅看共振」只看多级别共振信号
- **导出 CSV**：点击按钮下载（UTF-8 BOM，Excel 直接打开）；**生成报告**：一键生成自包含 HTML 报告

### 同步服务器数据

勾选「同步服务器数据」后，每次执行筛选前先把服务器最新 K 线**增量同步**到本地缓存（本地已有则仅拉取最近 5 根对比追加，本地缺失则全量拉取），并记录同步时间显示在开关下方「上次同步」处。

- 增量同步避免重复下载历史数据，全市场场景下单日流量可降低约百倍
- 停牌股增量拉取无新 bar 属正常，自动跳过
- 同步状态可通过 `GET /api/sync/status` 查询，或 `POST /api/sync` 手动触发

### K线图弹窗

- 点击结果行，弹出该股票的 K 线图
- 图表包含：蜡烛图（涨红跌绿，符合 A 股配色）、MA5/10/20/60、成交量副图
- **形态高亮**：命中形态的 K 线区域用半透明色块 + 边框高亮，弹窗顶部图例列出该级别命中的全部形态
- 支持缩放/平移（鼠标滚轮 + 底部滑块）

## 数据来源与更新频率

### 数据源

| 数据 | 来源 | 协议 | 说明 |
|------|------|------|------|
| 日/周/月线 K 线 | **通达信 mootdx** | TCP 7709 | 不封 IP、无需鉴权，主数据源 |
| 股票名称/现价 | 腾讯财经 | HTTP | 批量快照，不封 IP |
| 全市场股票列表 | 通达信 mootdx | TCP | 沪深 A 股约 5000 只 |

### 更新频率

- **日终批量扫描（主）**：每个交易日收盘后（约 15:00 之后）运行一次，扫描当日全市场
  - 日线为完整交易日数据
  - 周线在周五收盘后完整，月线在月末完整（`INCLUDE_FORMING_BAR` 可控制是否纳入未收盘的周/月 K 线）
- **本地缓存**：K 线落盘到 `output/cache/v1/`，同周期内重复扫描直接读缓存，减少重复拉取
- **命令行定时任务示例**（Windows 任务计划 / Linux crontab）：
  ```bash
  # 每交易日 15:30 全市场日线扫描
  python run.py --scan --full --tf daily --volume-min 1.5 --sort-by strength
  ```
